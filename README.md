# Tecnologia e Desenvolvimento de Sistemas

## Objetivo do Projeto
Este projeto foi desenvolvido com o objetivo de aplicar boas práticas de desenvolvimento Front-End, utilizando HTML5 semântico e CSS3 organizado em arquivos separados, além de praticar o versionamento de código com Git e GitHub.

## Estrutura do Site
O site apresenta informações introdutórias sobre a área de Desenvolvimento de Sistemas e destaca três tecnologias fundamentais da web:
- **Cabeçalho e Navegação:** Acesso rápido às seções da página.
- **Sobre Desenvolvimento de Sistemas:** Explicação conceitual sobre a área.
- **Tecnologias Web:** Cards informativos sobre HTML5, CSS3 e JavaScript.
- **Rodapé:** Créditos da equipe desenvolvedora.

## Como foi desenvolvido
1. **Estruturação (HTML5):** Criação de código limpo, identado e semântico, utilizando classes descritivas.
2. **Estilização (CSS3):** Separação completa entre estrutura e estilo, uso de variáveis CSS para padronização de cores e Flexbox/Grid para alinhamento responsivo.
3. **Versionamento (GitHub):** Organização do repositório com commits descritivos registrando cada etapa da construção.
